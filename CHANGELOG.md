## 0.2.0 — 2026-08-02

- add localized runnable examples and JSON copy actions to all eight web tools
- add desktop and mobile browser interaction coverage
- add typed MCP outputs, structured errors, and three agent workflows
- add `textanalysis check` with a versioned configuration schema and GitHub Action
- publish the analysis core as an importable ESM TypeScript API
- add shared Hostinger filesystem rate limiting, dynamic quotas, and API pagination
- add tag-driven npm trusted publishing and exact-tarball release verification

  progress, input caps, bounded result rows, and visible partial-result notices

  an English privacy page, and revision-aware post-deployment verification
- bound CLI and MCP vocabulary and IDF outputs with explicit truncation metadata
- add aggregate MCP corpus safeguards and paginated comparison and IDF results
- audit production dependencies from the exact packed npm consumer artifact
