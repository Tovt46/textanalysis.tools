# Text Analysis Tools — мудборд редизайна

Дата: 9 сентября 2026. Откройте `index.html` в браузере; сборка, сервер и установка зависимостей не требуются. Папка `screenshots/` должна находиться рядом с HTML.

Мудборд охватывает главную страницу и рабочие инструменты для SEO-специалистов, их агентов, редакторов и авторов. Выбранное направление — сдержанный интерфейс с характером, ориентир Linear / Raycast. Это исследование и подборка приёмов, не макет и не реализация редизайна.

Визуальные опоры: Linear, Raycast, Resend. Функциональные референсы: Ray.so, Diffchecker, Hemingway, WordCount, regex101. Сайты решают разные задачи; не все являются прямыми конкурентами. Ссылки на оригинальные страницы находятся в каждой карточке и в окне просмотра.

Возможности: фильтры, увеличение реальных скриншотов через нативный `dialog`, закрытие кнопкой или Escape, возвращение фокуса к исходному изображению, два переключаемых варианта акцента, сворачиваемая текущая главная. Тёмная тема относится к оформлению мудборда; тема будущего сервиса и акцент пока не выбраны.

Палитра в блоке «Собственное предложение» разработана для обсуждения и не является извлечёнными токенами референсов. Превью и увеличенный просмотр показывают сохранённые кадры целиком. Изображения используются как исследовательские референсы с атрибуцией владельцам.

Артефакт автономный: HTML, встроенные CSS/JavaScript, локальные PNG. Внешние зависимости, трекеры и удалённые шрифты отсутствуют. Продуктовые файлы не менялись. Деплой не выполнялся.
